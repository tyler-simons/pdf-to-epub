# Security

Do not put credentials, private documents, job access tokens, or unredacted logs in public issues.

For a vulnerability involving secret exposure or unauthorized document access, contact the maintainer privately through the contact details on https://tylersimons.com before opening a public report. Revoke any exposed credentials promptly.

Rebind processes untrusted PDFs with subprocess resource ceilings, but these are not a complete hostile-code sandbox. Use isolated infrastructure, private object storage, durable rate and spend limits, and your own provider-level controls for public deployments.
